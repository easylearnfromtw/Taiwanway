# 閒台文 GitHub Pages 版本（無後端）

此版本把原本內嵌在 `index.html` 的大型音訊、影片、圖片與 PDF 拆成靜態檔案。
好友／同窗資料仍使用瀏覽器本機 IndexedDB，不需要 Supabase、Firebase 或任何後端。

## 上傳方式
把這個資料夾內的內容保持原本結構上傳到 GitHub repository 根目錄：

- `index.html`
- `assets/`
- `audio/`
- `soundscape/`

不要只上傳 `index.html`，否則人物卡、聲音、證書等資產會找不到。

GitHub Pages Source 設定為 repository 的 main branch / root 即可。
